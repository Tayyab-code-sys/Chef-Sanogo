# Chef Sanogo Brahema

Website and digital contact card for **Chef Sanogo Brahema**, Corporate Chef at Royal Private Affairs, Riyadh.

- `index.html` — main landing page
- `card.html` — tap-to-save contact card (opened by the QR code)
- `contact.vcf` — vCard download
- `favicon.svg` — site icon
- `chef.jpg` — chef photo

Static site. No build step. Open `index.html` or deploy the folder as-is (Vercel config included).
